# 📝 Blog — Frontend

Este é o **frontend** de um Blog, desenvolvido com **HTML, CSS e JavaScript puro**, sem frameworks ou bibliotecas.  

Ele consome a [API do backend (Flask)](https://github.com/Bebel132/blog-api) para exibir e gerenciar posts.
